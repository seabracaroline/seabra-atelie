# Seabra Ateliê – Sistema de Gestão

Sistema web desenvolvido para apoiar a gestão de clientes e pedidos do **Seabra Ateliê**, um negócio familiar especializado na produção artesanal de itens personalizados.

O projeto foi desenvolvido como atividade acadêmica do curso de **Análise e Desenvolvimento de Sistemas**, com foco na aplicação prática de conceitos de análise, modelagem, desenvolvimento web, testes e versionamento de software.

---

## Objetivo

O objetivo do sistema é facilitar a organização e o gerenciamento das atividades do ateliê, permitindo o cadastro de clientes, controle de pedidos e acompanhamento de prazos por meio de uma agenda interativa.

---

## Funcionalidades

✅ Cadastro de clientes  
✅ Edição de clientes  
✅ Exclusão de clientes  
✅ Cadastro de pedidos  
✅ Alteração de status dos pedidos  
✅ Agenda interativa com calendário  
✅ Validação de dados de entrada  
✅ Controle de dados duplicados  
✅ Armazenamento local com LocalStorage  
✅ Interface responsiva e intuitiva
