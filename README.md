# 🎨 Seabra Ateliê — Sistema de Gestão

Sistema web desenvolvido para auxiliar na gestão de clientes e pedidos de um ateliê de produtos personalizados.

---

## 📌 Sobre o Projeto

O sistema permite:

- Cadastro de clientes
- Cadastro de pedidos
- Visualização de pedidos em tabela
- Controle de status dos pedidos
- Visualização em calendário

A aplicação foi desenvolvida utilizando **HTML, CSS e JavaScript**, com armazenamento local via **LocalStorage** e hospedagem no **GitHub Pages**.

---

## 🚀 Funcionalidades

### 👥 Clientes
- Cadastrar clientes
- Editar clientes
- Excluir clientes (com confirmação)
- Listar clientes

### 📦 Pedidos
- Cadastrar pedidos
- Editar pedidos
- Excluir pedidos (com confirmação)
- Alterar status (Pendente, Em andamento, Concluído, Cancelado)

### 📅 Agenda
- Visualização dos pedidos em calendário
- Cores indicam o status do pedido
